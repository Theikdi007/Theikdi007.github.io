Case study 03 · Kids education · Performance

Picture books that turn instantly

Marvelo Book is a reading app for children, with illustrated picture books, read-aloud narration, coloring and rewards. Kids don't wait for a spinner, so every page has to be there the moment they swipe.

Role
Senior Flutter Developer
Stack
Flutter · GetX
Platforms
iOS & Android

Get the app: App Store ↗ · Google Play ↗

01 / The setup

A library of illustrated books for kids

Parents set up child profiles, and kids read illustrated books with read-aloud narration, color pictures and earn reward points. The app is built in Flutter with GetX.

02 / The problem

Big illustrations made reading slow

Every page of a picture book is a large, detailed illustration. Loading each one only when the child swiped meant a blank page or a spinner, especially on mobile data and mid-range phones.

For young readers that breaks the story. They tap again, get confused or give up.

03 / The fix

Smaller images, cached, and always one page ahead

I attacked the delay at every step between the server and the screen.

01

Smaller images from the server

Pages and list thumbnails are sized for phone screens, so there are fewer bytes to download.

02

Cache on the device

A page is downloaded once and then read from the phone, so going back is instant.

03

Prefetch the next pages

While a child reads one page, the next pages load quietly in the background.

04

Download a book for offline

Families can save a whole book and read it with no internet at all.

// Simplified: warm up the next pages while the current one is showing.
void onPageChanged(int index) {
  for (final next in [index + 1, index + 2]) {
    if (next < pages.length) {
      precacheImage(CachedNetworkImageProvider(pages[next].url), context);
    }
  }
}
04 / The result

Page turns that keep up with a child

Pages that have been seen, prefetched or downloaded open straight from the device, so most swipes show the next illustration immediately, and whole books work on a plane or in a village with no signal.

1×each page is downloaded only once
Aheadnext pages prefetched while reading
Offlinewhole books saved to the device

What I took from it: performance work is most valuable where the user is least patient. Measuring from the child's swipe, not from the API call, showed where the time really went.
